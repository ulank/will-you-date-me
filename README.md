# Менімен кездесуге барасың ба? 💛

Қазақ ұлттық нақышындағы (қошқар мүйіз өрнегі, көк/алтын/қызыл палитра) бір беттік
шақыру сайты. Фреймворксіз: таза HTML + CSS + JS.

## Не бар

- **«Жоқ» батырмасы қашады** — десктопта тінтуір жақындағанда, мобильде саусақ
  жақындағанда/тигенде (тек кликке емес: `touchstart`/`touchmove` арқылы).
- **Шекара бар**: батырма бүкіл экранға емес, тек көрінетін ойын алаңының
  (`.arena`) ішінде қозғалады — сыртқа шыға алмайды.
- **«Иә» батырмасы** — кездесуді жоспарлау қадамдары ашылады:
  түрі (тамақ ішу, тауға шығу, кино, …) → нақтылау (асхана түрі, т.б.) →
  күні мен уақыты → телефон нөмірі.
- **Жауап Telegram-ға келеді** — соңында таңдалғанның бәрі ботпен саған жіберіледі,
  экранда фейерверк атылады.
- Гифкалар Giphy-ден жүктеледі. Ауыстыру үшін `index.html` ішіндегі екі
  `<img class="gif" ... src="...">` сілтемесін өзгертіңіз. Сілтеме істемей қалса,
  сурет орны бос қалмай, автоматты жасырылады.
- iPhone/iPad/десктопқа адаптивті, iOS `safe-area` ескерілген.
- Сыртқы кітапхана, шрифт, сурет жоқ — 3 файл, жүктемесі минимал.
- `prefers-reduced-motion` қолдайды.

## Баптау

`script.js` файлының басындағы `CONFIG`:

```js
const CONFIG = {
  name: 'Жанерке',             // кімді шақырамыз
  telegram: {
    botToken: '',              // @BotFather берген токен
    chatId: '',                // сенің chat id-ің
  },
};
```

Кездесу түрлері мен нұсқалары — `script.js` ішіндегі `DATE_TYPES` тізімінде.

### Telegram-ды қосу

1. Telegram-да [@BotFather](https://t.me/BotFather) → `/newbot` → токенді `botToken`-ға қой.
2. Жаңа ботыңа кіріп, **Start** бас (әйтпесе бот саған жаза алмайды).
3. `https://api.telegram.org/bot<ТОКЕН>/getUpdates` сілтемесін ашып,
   `"chat":{"id":…}` санын `chatId`-ға қой.

Токен сайт кодында ашық тұрады, сондықтан осы сайтқа ғана арналған бөлек бот жаса.
Хабар жіберілмесе — нөмір қадамында қате көрсетіледі, қайта жіберуге болады.

## GitHub Pages-ке деплой

```bash
git add .
git commit -m "Кездесуге шақыру"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

Содан кейін: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root` → Save**.
1–2 минуттан кейін сайт `https://<username>.github.io/<repo>/` мекенжайында ашылады.

## Жергілікті қарау

```bash
python3 -m http.server 8000
# http://localhost:8000
```
